## 武夷茶典

**武夷学院图书馆特色茶文化 AI 智能体**

面向茶文化学习与图书馆资源查询，将知识检索、问答交互和资料来源连接起来。

- **个人工作**：开发网页交互与 Node.js 服务，组织专题知识与系统提示词，集成中文 bigram 倒排索引、分层检索、流式回答、来源展示与 OPAC 查询模块。
- **技术使用**：JavaScript、Node.js、RAG、OpenAI 兼容接口、Markdown 渲染。
- **展示状态**：[在线体验](https://app-oziaruifvfkj.cxiagents.com/)。已核对一次带来源的问答流程；实时馆藏和回答质量仍需分别验证。线上部署版与本地整理版未作逐文件一致性核对。

## 景区路人消除

**智能景区路人消除与拍照背景修复系统**

用户选择需要保留的人物后，系统生成其他人物的消除区域，并尝试补全背景。

- **个人工作**：集成人物检测、SAM 掩膜、主角保护、LaMa 修复与 PyQt5 三栏界面，实现图片导入、人物选择、处理结果展示与保存。
- **技术使用**：Python、PyTorch、YOLO11x-seg、SAM ViT-B、LaMa、OpenCV、PyQt5。
- **验证范围**：两张样例已完成 CPU 集成测试、主角区域保护与原尺寸 PNG 导出。复杂遮挡和背景补全仍可能出现残影、涂抹，GPU 与完整手动桌面流程尚未验收。

## 竹材壁厚测量

**基于 YOLO 实例分割的竹材截面最小壁厚智能测量系统**

从竹材截面图片中分割内外轮廓，计算距离并生成标注图与 CSV 结果。

- **个人工作**：Labelme 标注转换、YOLOv8 分割训练与预测、轮廓距离分析、像素与毫米换算及结果输出。
- **技术使用**：Python、Ultralytics YOLO、OpenCV、NumPy、SciPy。
- **测量边界**：原实现以固定外径假设换算毫米，并对轮廓顶点距离作阈值筛选；尚缺少逐样本真实标定与卡尺对照，暂不宣称毫米级精度或工业测量能力。
